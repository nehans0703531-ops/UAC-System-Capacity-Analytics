# 🏥 System Capacity & Care Load Analytics for Unaccompanied Children

<p align="center">

**An Interactive Data Analytics, Capacity Monitoring & Forecasting Dashboard for the UAC Care System**

</p>
📌 Project Overview
System Capacity & Care Load Analytics for Unaccompanied Children is a data analytics and decision-support project designed to analyze reported data associated with the Unaccompanied Alien Children (UAC) Program.

The project focuses on understanding the movement of children through different stages of the care system, including:
CBP Custody
      ↓
Transfer from CBP
      ↓
HHS Care
      ↓
Healthcare / Welfare Support
      ↓
Discharge / Placement

The system combines data preprocessing, exploratory data analysis, capacity-related metrics, high-load detection, visualization, and short-term forecasting into an interactive Streamlit dashboard.

The primary objective is to transform raw program-level data into meaningful analytical insights that can support understanding of:
- System workload
- Care load
- CBP custody levels
- HHS care levels
- Intake and discharge patterns
- High-load periods
- Changes in system burden
- Short-term future workload trends
🎯 Problem Statement
The UAC care system involves multiple stages of custody, transfer, care, and discharge.

When information about these stages is analyzed separately, it can be difficult to understand the overall workload and changing pressure on the system.

A centralized analytical framework is therefore useful for answering questions such as:
- How many children are represented across the care system?
- How does the total system load change over time?
- How many children are in CBP custody?
- How many children are in HHS care?
- How do transfers and discharges compare?
- When does the system experience relatively high workload?
- What are the recent workload trends?
- What could the short-term system load look like?
This project addresses these questions through a centralized analytics dashboard.

📊 Dataset
The project uses reported UAC program data containing information about children in different stages of the care system.
Dataset Columns
Column	Description
Date	Reporting date
Children apprehended and placed in CBP custody*	Number of children apprehended and placed in CBP custody
Children in CBP custody	Children reported in CBP custody
Children transferred out of CBP custody	Children transferred out of CBP custody
Children in HHS Care	Children reported in HHS care
Children discharged from HHS Care	Children discharged from HHS care


📅 Dataset Time Period
The dataset contains reported observations covering:
January 2023 – December 2025
The dataset contains both populated and blank rows in its original form.
After preprocessing:
- Completely empty rows are removed.
- Invalid dates are removed.
- Numeric values are converted into appropriate numeric formats.
- Comma-formatted values are cleaned.
- Records are sorted chronologically.
- Duplicate reporting dates are checked.
Important Data Consideration
The reporting dates are not uniformly spaced across the complete period.

Therefore, this project does not assume that every observation represents a complete calendar day.

Temporal analysis is performed using the available reported observations.
